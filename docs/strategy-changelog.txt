TESTSTOCK STRATEGY CHANGE LOG

This file records changes to trading RULES, thresholds, tiers, sizing, validation, and safety behavior. Routine market-data refreshes and changing trade signals are intentionally not listed here.

2026-08-19 — PERFORMANCE-GATED RISK SCALING
- Added performanceScalingGuard so account equity alone can never unlock more aggressive trading risk.
- The normal capital ladder still selects the equity tier, but Claude must also compute an effective risk tier from confirmed real-money performance and use the more conservative settings.
- Before SCALE risk can be used, Teststock requires at least 20 resolved real trades, average realized R >= 0.20, win rate >= 45%, reliable observed drawdown below 6% when available, and no active real-fill, slippage, protection, health, persistence, or circuit-breaker block.
- Before GROWTH risk can be used, Teststock requires at least 30 resolved real trades, average realized R >= 0.30, win rate >= 48%, reliable observed drawdown below 6% when available, and all other guards passing.
- Manual deposits or account profits may raise the equity tier but cannot by themselves unlock higher risk. Missing or ambiguous performance evidence never unlocks more aggression.
- Signal schema advanced to v16.

2026-08-19 — SYSTEM HEALTH + PERSISTENCE + EXECUTION TELEMETRY
- Added machine-readable systemHealth policy to signal.json. Critical dependencies now fail closed: stale/missing/contradictory Teststock data, unknown Robinhood balances/orders/positions, failed journal/history reconciliation, or unavailable required protective-exit capability means no new position.
- Added a visible System Health dashboard to the public Teststock page. GitHub-side signal/validation status is shown directly; Robinhood, protective-exit, and journal-persistence checks are clearly marked as runtime checks rather than guessed.
- Added a cross-run journal persistence self-test using a nonce. Claude may mark the journal PERSISTENT only after a later scheduled run reads back the same nonce. Failed/unverified persistence falls back to Robinhood-history reconstruction and may never justify more risk.
- Expanded real-fill execution telemetry to include order type/price, bid/ask spread at submission when available, time-to-fill, adverse slippage, protective-order creation/verification timing, and protection latency. Missing telemetry remains unknown rather than inferred.
- Added a protective-order reliability guard: if enough recent supported stock/option entries exist and verified protection falls below 90%, pause new stock/option entries until reliability is restored.
- Added one concise daily summary policy covering account value, cash, positions, planned risk, realized P&L, trades, regime, blocked setups, system health, and journal persistence.
- Added a minimum shadow-evidence rule: at least 30 resolved ACCEPTED and 30 resolved REJECTED shadow decisions are required before shadow results can justify even a manual gate-review discussion. Shadow data can never automatically loosen live-money rules.
- Signal schema advanced to v15 and signal validation now requires fail-closed health metadata, execution-telemetry source-of-truth, daily-summary policy, and shadow sample floors.

2026-08-19 — HOLDOUT VALIDATION + REGIME-SPECIFIC RISK + EVENT/SLIPPAGE/SHADOW GUARDS
- Entry-gate validation now uses a chronological development period and an untouched holdout period beginning 2024-01-01. The fixed 52% historical win-rate, 2.5:1 reward/risk, 15-sample, and 0.5R conservative-expected-value thresholds are not tuned on the holdout.
- Validation now publishes a runtime policy separately for calm, volatile, trending-down, trending-up, mixed, and unknown regimes. Weak holdout regimes can block new risk; sparse regimes automatically reduce stock size and block options. Regime validation may only reduce risk, never loosen the base gates.
- Added event-risk blackouts before new positions: high corporate-action risk blocks entries; stock entries are blocked around the estimated report window from 3 days before through 1 day after; options use a stricter 7-day pre-event window through 1 day after. Estimated dates remain uncertain, so the guard is intentionally conservative.
- Added real-fill adverse-slippage learning. With enough confirmed fills, repeated bad execution can reduce size or block the exact stock/option/crypto setup, cluster, or symbol bucket. Robinhood fills remain authoritative.
- Added a paper shadow ledger that tracks both accepted and rejected Teststock candidates and later measures modeled R/opportunity cost from future Alpaca bars. Shadow results are diagnostic only and can never automatically increase live-money risk or override Robinhood real-fill results.
- Claude scheduled instructions now explicitly apply holdout-regime scaling, event blackouts, slippage learning, and the rule that shadow data cannot be treated as real P&L.

2026-08-18 — MULTI-REGIME VALIDATION + WHOLE-CONTRACT OPTION SAFETY
- Added a wider historical entry-gate validation covering calm, volatile, trending-down, trending-up, and mixed SPY regimes.
- Current thresholds under review are: 52% historical win rate, 2.5:1 minimum reward/risk, 15 minimum historical samples, and 0.5R minimum conservative expected value.
- Added a RED_FLAG result when required calm, volatile, or trending-down regime checks do not hold up.
- Added explicit whole-contract option sizing: one real contract must fit the live dollar risk cap. Percentage sizing may never imply a fractional contract.
- Added signal.json generation validation for JSON structure, timestamp freshness, tier boundaries, field ranges, and option-risk metadata.
- Added last-known-good signal fallback if a fresh signal build or validation fails.
- Expanded real-fill learning to report and react to performance separately by setup type and correlation/risk cluster, in addition to overall performance.

2026-08-18 — CAPITAL TIER BOUNDARY CLARIFICATION
- Capital tiers changed to explicit lower-bound-inclusive / upper-bound-exclusive intervals.
- Exactly $80 = DEFENSE; exactly $100 = PROVE; exactly $125 = SCALE; exactly $150 = GROWTH.
- Added machine-readable exact boundary examples to reduce agent interpretation errors.

2026-08-18 — REAL ROBINHOOD FILL LEARNING
- Added Teststock-Real-Trades journal schema and Robinhood-authoritative reconciliation policy.
- Added actual fill, exit, P&L, slippage, realized-R, protective-order, and exit-reason tracking.
- Real-fill learning can reduce risk, lock options, or pause entries; it cannot make the strategy more aggressive than existing Teststock limits.

2026-08-18 — FULL-AUTO SAFETY LAYER
- Added $75 hard account floor with $80 recovery threshold.
- Added daily/weekly trade-frequency limits, correlation protection, circuit breakers, execution-quality limits, automatic protective exits, profit management, and health guards.
- Funding remains user-only: the agent may never initiate deposits, transfers, withdrawals, or external funding.
