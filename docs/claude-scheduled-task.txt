Buy only when eliteOption is AUTO_BUY_ELIGIBLE, every elite check remains true, the active ladder tier allows options, the exact contract exists, live spread/liquidity is acceptable, and total premium/risk is no more than the SMALLER of eliteOption.maxRiskPctOfRobinhoodBuyingPower and the active tier maxOptionRiskPct. 14. Never increase risk to chase a profit target or recover losses. Unused buying power stays cash.
15. If no action is required, report only a short status. If a trade or exit occurs, report ASSET CLASS, symbol/contract, action, dollar amount/risk used, execution price if available, active capital-ladder tier, stop/invalidation, targets, and remaining buying power.
